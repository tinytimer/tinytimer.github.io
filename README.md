# Tiny Timer — public support & legal pages

Static site serving the three URLs Apple requires for App Store submission, plus a
landing page:

| Page | Path |
| --- | --- |
| Home | `/` |
| Support | `/support/` |
| Privacy Policy | `/privacy/` |
| Terms & Conditions | `/terms/` |

Operated by THE FLOCO COMPANY, LLC. Contact: tinytimer.support@gmail.com

## Why plain HTML

The content originated in a Next.js 16 / Cloudflare Workers project
(`../tiny-timer-site`) generated by Codex's Sites tooling. That scaffold depends on
`vinext`, a Codex-specific shim, and it could not be published because Sites hosting was
never enabled for that workspace. Since these are four static pages that change perhaps
once a year, the content was ported to plain HTML + one stylesheet.

The result has no build step, no dependencies, no server, and no third-party requests —
that last point matters for pages that describe what data isn't shared. `styles.css` is
the original `globals.css` verbatim, minus a vestigial Tailwind import and with the Geist
webfont swapped for a system stack.

`../tiny-timer-site` is kept only as the content's provenance. Nothing here depends on it.

## Live at

**https://tinytimer.github.io/**

Published via GitHub Pages from `main` / `/ (root)`, in the GitHub org `tinytimer`
(owned by THE FLOCO COMPANY, LLC). The repo is named `tinytimer.github.io` — matching the
org name exactly — which is what makes GitHub serve it at the root rather than at a
`/repo-name/` subpath. **Renaming this repo would move the site and break the URLs
compiled into the shipped app.**

The repo must stay **public**; GitHub Pages on a private repo requires a paid plan. It
contains no secrets. `.nojekyll` is present so GitHub serves the files as-is.

The local folder is still named `tiny-timer-web` — that mismatch is harmless and only
affects what GitHub Desktop displays.

| App Store Connect — Support URL | https://tinytimer.github.io/support/ |

Trailing slashes are intentional: these are directory indexes, so omitting them costs a
redirect hop.

## Adding a custom domain later

All internal links are relative, so the site already works at any base path — moving to a
custom domain needs no file changes.

If you register `tinytimer.app`: Settings → Pages → Custom domain, point DNS at GitHub,
and enable Enforce HTTPS (`.app` is HSTS-preloaded, so HTTPS is mandatory). Then update
`legal.ts` and App Store Connect.

Keep `tinytimer.github.io` reachable until an app build carrying the new links has
shipped and users have updated — the old URLs stay live in every installed copy.

## Editing

Open the `.html` file and edit the text. There is no build step. Header and footer markup
is duplicated across the four pages — intentional, to keep the site dependency-free. If
you change navigation or the footer, update all four.

When changing legal text, also bump the effective date (`Effective August 1, 2026` in the
`.legal-hero` block of `privacy/` and `terms/`) and `TERMS_VERSION` in the app's
`src/constants/legal.ts` if the change is material.
